# RISC-V-32-bit-microprocessor
A 32-bit RISC-V RV32I microprocessor with a 5-stage pipeline (IF, ID, EX, MEM, WB), written in Verilog for Xilinx Vivado. It features data forwarding, load-use stalls, and branch flushing, plus a Basys 3 FPGA top level with single-step control and a 7-segment register display. Verified with self-checking and randomized testbenches.
